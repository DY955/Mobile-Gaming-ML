# Competitive Mobile Gaming Match Outcome & Deck Strategy Predictor

## Overview
A data science project that fetches live match history data from public gaming REST APIs to predict match outcomes and uncover optimal card synergy archetypes in competitive PvP matches.

## What This Project Does
- **API Data Pipeline**: Automatically fetches top-tier ladder match results and player statistics using Python requests.
- **Feature Engineering**: Calculates card synergy scores, elixir-cost ratios, and win-rate percentages across varying matchups.
- **Machine Learning Classification**: Trains a Logistic Regression and Random Forest model to predict match outcome probability based on deck selection.

## Tech Stack
- Python, REST APIs, Pandas, Scikit-Learn, Matplotlib, Seaborn
